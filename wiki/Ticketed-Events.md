Here are the step-by-step instructions on how to create a ticketed event for Heatsync. This can be used for RSVP hosted hours or other events.

- Login to [guestlist.co](https://guestlist.co/)
  - Username: instructors@heatsynclabs.org
  - Password: [Hunter2](https://knowyourmeme.com/memes/hunter2) (Not really. You'll have to get it from an existing member)
- Go to the [Dashboard](https://guestlist.co/manage/events) (upper left corner)
- Find a class/hosting that looks like yours and copy it.

![](files/Copy.png)

*copy.png*

- - Edit the date and time.
  - Edit the tickets details.
  - Lather
  - Edit event details
  - Preview.
  - Rinse.
  - Correct errors.
  - Preview again.
  - Repeat
- Publish.

![](files/Guestlistdashboard.png)

- Copy link.
- Share link.
- Log in prior to event to see who has signed up.
