# Overview

This is a transcription of the hand written instructions in the binder from Nancy Gibson. I just wanted to get them digital to then be able to update/maintain.

# Design

1.  Design an image or find a black and white image on google.
2.  Drag image onto the desktop or save it
3.  Open [Sure Cuts a Lot](Sure-Cuts-a-Lot) program and drag image over into the program or import/open file.
4.  Select image. Go to File -\> Trace image, click on it. (If you designed the image you can skip this step)
5.  From Trace Image a menu will pop-up. Click on 'Ok'
6.  Drag old image (one you can't see the grid behind) away from the new image.
7.  Delete the old image.
8.  Your image is left.
9.  This is a close up of my turtle image. (Jot's note need to add these in, but they're other pages in the binder). See how at the highlighted points the line does not connect. That part will not be cut. So, when you weed it you will have to cut it. To prevent this, when finding an image be sure all the lines you want to cut connect.
    1.  (From back of page) For most things set speed (SPD) to 300 and PRS to 177 and test to see if it cuts.
    2.  (From back of page) Press enter to show 'local' - it won't cut unless local is showing
10. Turn on vinyl cutter
11. Go to menu board on cutter and push enter
12. Push select
13. Keep pushing select until 'current' is highlighted.

## Machine setup

1.  Setting up the machine
    1.  Set pressure is left and right arrows. Speed on local settings is up and down arrows.
2.  This pic shows the blade is not in the machine (Jot's note: need to embed pic)
3.  Shows where the blade and pen are stored
4.  Putting blade in cutter
5.  Close and tighten it
6.  Put the vinyl in the machine
7.  Be sure rollers are in line with white brackets above. If this is not done vinyl will move and cutting will not be right.
    1.  A shows how bottom rollers are aligned with white bracket above.
8.  Lock rollers down with the handles in back
9.  With menu on 'current' push arrows until blade is where you want to start.

## Cutting

1.  Go back to computer in Sir Cuts A Lot program. Click on icon with scissors.
2.  Next menu - click on 'cut'
3.  Cutting will show on computer
4.  Some time it will show 'sent to machine'. Click on 'ok'
