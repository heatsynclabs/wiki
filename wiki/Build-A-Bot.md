## Overview

Build-A-Bot is a workshop where you design, laser cut, and solder your own robot that lights up and changes color when you touch it's heart. This originally was a 3 hours class that rushed through all the steps with 4 people teaching the workshop. Current iteration will be 2 events where you can do either event or both.

If you are only doing the first event you can make your own non-electronic robot that works as a figure. Doing them both you can create a custom electronic version.

**Inkscape Design Class (Design A Bot)** will be posted as Inkscape Design Class. This event works great for anyone interested in designing things for the laser cutter or vinyl cutter. With demonstrations of the vinyl cutter and laser cutter.

**Build-A-Bot!** Anyone age 7 and up can solder a robot. We will have several robots to choose from if you don't have a custom design already.

## Inkscape Design Class / Design A Bot

Build-A-Bot is 2 events \$15 each, \$30 total tickets sold separately.

In this class Eric Ose will show you how to create vector designs with Inkscape for use with the vinyl cutter or laser cutter. How to import images and trace them, how to trace things manually, how to edit nodes, how to combine shapes to make new shapes, how to deal with objects as well as exporting to dxf for the 80 Watt laser cutter.

We will be using Inkscape 1.3 (or later release). Laptops are provided, but you can also bring your own laptop with it installed and select a "Bring Your Own Laptop" ticket.

This class works as a solo class or as part of the Build-A-Bot series. See this link for more details. It is also best for adults and kids age 10 and up, but parents can work with their younger kids if they want.

At the end of class we will laser cut the robots.

## Solder a Robot

Join us for a hands-on make and take soldering project. You will make your own fun robot figure that lights up when you touch it's heart. This robot is a great demonstration of how transistors work to boost the signals from a sensor. No experience necessary. Adults and kids age 7 and up welcome. Don't miss the fun!

This class works as a solo class or as part of the Build-A-Bot series of classes. See this link for more details. If you aren't designing a robot you'll be able to pick from a list of ahead of the event.
