# Overview

The lab has 12 laptops for hosting classes and events. These were [proposed in 2020](https://groups.google.com/g/heatsynclabs/c/q1L8OEhr43w/m/EY0JtLqNAQAJ). This [post](https://groups.google.com/g/heatsynclabs/c/LZDUuxmxo6s/) has specifics on the laptops.

Dell Latitude E7470 (Refurbished)

- Intel Core i5-6200U / Core i5-6300U
- Intel HD Graphics 520
- 8GB DDR4 (4GB x 2)
- 256GB M2 Solid State Drive
- 14" Full HD 1920x1080 screen
- Windows 10 Pro
