One of the most common uses for the lasers is to create boxes. Now, you could design these all yourself in [Inkscape](Inkscape) or you could be efficient and lazy. I recommend the latter. You can also make parameterized boxes in Fusion360, as a tool to help learn fusion. To do that you'll want to use one of the online box generators.

# On-line box generator sites

- [Ultimate Guide Instructable](https://www.instructables.com/id/The-Ultimate-Guide-to-Laser-cut-Box-Generators/)
- [Simple box generator](https://en.makercase.com/#/)
- [Online site that uses python to generate a bunch of interesting boxes](https://www.festi.info/boxes.py/)
- [Patterns for paper/cardboard boxes](https://www.templatemaker.nl/en/)
